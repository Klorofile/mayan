# App Routes

Route group `(app)` berisi halaman utama setelah login.

## Layout

`layout.tsx` membungkus semua halaman dengan:

- Sidebar navigasi kiri.
- Topbar sticky.
- Main content responsive max-width.

## Pages

- `dashboard` — executive overview dan reusable component showcase.
- `employees` — employee management.
- `attendance` — attendance records.
- `leave` — leave request.
- `payroll` — payroll records.
- `recruitment` — placeholder recruitment.
- `performance` — placeholder performance.
- `reports` — reporting placeholder.
- `settings` — settings placeholder.
