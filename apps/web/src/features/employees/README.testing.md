# Employee Form Testing

Testing frontend employee management memakai Vitest.

## File

- `employee-form.test.ts` memvalidasi `employeeSchema`.

## Tujuan

- Menjaga field penting seperti `employeeNumber`, `fullName`, `email`, `hireDate`, dan `status` tetap tervalidasi.
- Mencegah perubahan schema form yang tidak sengaja merusak kontrak payload ke API.
