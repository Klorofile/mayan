# Web Components

Folder ini berisi komponen reusable dan feature-level untuk MAYAN frontend.

## Layout

- `layout/sidebar.tsx` — navigasi kiri dengan neon green SaaS style.
- `layout/topbar.tsx` — search, notification, profile, logout.

## Reusable Patterns

- `feature-card.tsx` — card statistik dashboard.
- `reusable-table.tsx` — table generic untuk berbagai data module.
- `reusable-form.tsx` — reusable form shell untuk create/update flow.

## UI Primitives

Komponen di `ui/` mengikuti gaya Shadcn: kecil, composable, mudah dipindah atau diganti oleh generator Shadcn resmi.
